# 🕒 Security & Arbeitszeit Tracker

Eine moderne Web-App zur Erfassung von Schichten, Zuschlägen und Arbeitsorten.

- Vollständige Offline-Datenspeicherung (`localStorage`)
- JSON Backup Im-/Export
- `.csv` & Kalender (`.ics`) Export-Funktionen
- Automatischer Nachtzuschlag & Feiertagsberechnung

Diese App kann über **GitHub Pages** bereitgestellt werden.
